# Install Packet Tracer (Mac) + First Network



## What is Packet Tracer

Cisco Packet Tracer is a network simulation tool created by Cisco.

It allows you to:

* build networks (PCs, switches, routers)
* connect devices using cables
* assign IP addresses
* test connectivity (ping)
* troubleshoot network issues

### Why it is used

* to understand how networks actually work
* to visualize communication between devices
* to practice safely without real hardware
* to build foundational networking skills used in cloud (AWS, Kubernetes)

# STEP 1 — Create Cisco Account

Open:

👉 [https://www.netacad.com/](https://www.netacad.com/)

Actions:

1. Click **Sign Up**
2. Create account (email + password)
3. Verify email
4. Log in

---

# STEP 2 — Download Packet Tracer (Mac)

Open:

👉 [https://www.netacad.com/resources/lab-downloads](https://www.netacad.com/resources/lab-downloads)

Actions:

1. Scroll to **Packet Tracer**
2. Select **macOS (.dmg)**
3. Download file

---

# STEP 3 — Install (Mac)

1. Open `.dmg`
2. Drag **Packet Tracer** → **Applications**
3. Open from Applications

If blocked:

* System Settings → Privacy & Security → **Open Anyway**

---

# STEP 4 — First Launch

1. Open Packet Tracer
2. Log in using Cisco account

* Represents a computer
* Used to send/receive data

---

* Connects devices in the same network

* Connects different networks

# STEP 7 — Configure IP Addresses

---

## PC0

* Open PC0 → Desktop → IP Configuration

Set:

```plaintext
IP Address: 192.168.1.1
Subnet Mask: 255.255.255.0
```

---

## PC1

Set:

```plaintext
IP Address: 192.168.1.2
Subnet Mask: 255.255.255.0
```

---

# STEP 8 — Test Connectivity

---

On PC0 → Command Prompt:

```shell
ping 192.168.1.2
```

---

### Expected Result

* **Reply** → network is working
* **Timeout** → configuration issue

---

# STEP 9 — Troubleshooting

---

Change PC1 IP:

```plaintext
192.168.2.2
```

---

Run ping again:

```shell
ping 192.168.1.2
```

---

### Result

* Communication fails

---

### Reason

* Devices are in different networks
* No router present

---

# STEP 10 — Fix

Change PC1 back:

```plaintext
192.168.1.2
```

---

Run ping again → success
